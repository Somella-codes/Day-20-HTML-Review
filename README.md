# Day-20-HTML-Review🔁

**The Focus**
Today wasn’t about learning new syntax. It was an "HTML Review" lab on freeCodeCamp. 
A checkpoint to test everything from Day 1 to Day 19 in one go.

**What I Reviewed**

**1. Core HTML Structure**
`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<main>` 
Reminded myself why semantic tags matter. Screen readers and SEO depend on them.

**2. Text + Sectioning**
`<h1>` to `<h6>`, `<p>`, `<section>`, `<article>` 
Proper heading hierarchy and grouping content so it makes sense, not just looks okay.

**3. Links and Navigation**
`<a>` tags, `target="_blank"` with `rel="noopener noreferrer"`, absolute vs relative paths: `/`, `./`, `../` 
No more broken links or guessing where files are.

**4. Media + Embedding**
`<img>` with `alt`, `<iframe>` with `title`, `width`, `height` 
Accessibility first. If a screen reader can’t use it, it’s not done.

**5. Accessibility + Best Practices**
`alt` text, `title` on iframes, correct heading order, semantic containers. 
HTML isn’t just for the browser. It’s for everyone.

**Reflection**
Review days are low-key my favorite. You don’t feel like you "learned" something new, but you realize how far you’ve come. 
19 days ago I didn’t know what an iframe was. Today I’m debugging paths and link states.
